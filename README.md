# brain-lag
A site where artists interpret my brain. built with HTML/CSS, hosted on Neocities.

Brain Lag is a personal creative project built from scratch with HTML and CSS
and hosted on Neocities. Each section of the site is designed as a "room" that
visitors explore by clicking objects in the scene.

## Rooms
- **The Burn Book**: the phrase rooms, starting with the Dark Room
- **Guestbook**: a Brooklyn alley; sign it by clicking the "SIGN HERE" sign
- **Gallery**: artist interpretations of the phrases
- **The Switchboard**: a public chat, opened from the telephone

## Design notes
- Point-and-click navigation inspired by The Neverhood
- Each room has its own folder and stylesheet
- Guestbook and art submissions are curated through forms instead of instant posting

## Built with
HTML, CSS, Neocities, Google Forms, Tally, Chatango
